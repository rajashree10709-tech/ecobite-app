# ecobite-app
"🌿 EcoBite is an AI-powered zero-waste kitchen assistant tackling UN SDG 12. It transforms household leftovers into custom-named gourmet recipes with strict portion controls, canvas plating visuals, and live sustainability impact tracking. Reduce food waste, save money, and cook smarter!"
